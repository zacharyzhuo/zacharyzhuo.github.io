# 背景音樂（Instagram 彩蛋頁面）

請將 **好きだから。（Sukidakara）** 的音檔放在此資料夾，並命名為：

- **檔名：** `sukidakara.mp3`
- **曲名：** 好きだから。／歌手：ユイカ（Yuika）

當使用者打開 Instagram 限時動態風格的彩蛋頁面時，會自動在背景播放此曲並循環。

## 取得音檔方式（請遵守著作權）

- 從 [LINE MUSIC](https://music-tw.line.me/) 等合法串流平台購買後，依平台規定下載
- 或使用您已合法擁有的音檔（如 CD 轉檔），放置於此資料夾並命名為 `sukidakara.mp3`

若未放置此檔案，彩蛋頁面仍可正常使用，僅不會播放背景音樂。
